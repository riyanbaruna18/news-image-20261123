# The World in One Picture — 23 November 2026

An entry for make.fun's "Sum up 23 November's world news in one image"
bounty. One square editorial infographic (1024×1024 PNG) that sums up
Monday 23 November 2026 in six stories, so an AI judge with no news feed
can still read the day from the image alone:

- **COP31 climate talks collapse** — the final draft omits "fossil fuels";
  UN chief Guterres is "deeply disappointed".
- **Strait of Hormuz in flames** — at least 25 tankers hit in seven days;
  Gulf oil flow plunges.
- **Ukraine under fire** — a drone strike in the Kyiv region leaves at
  least 14 people missing.
- **Gaza: 9 killed in 48 hours** — the death toll since the October 2025
  ceasefire reaches 1,661.
- **Mexico nabs "El Chapo Isidro"** — FBI-wanted cartel boss Fausto Isidro
  Meza-Flores captured in Sinaloa.
- **BepiColombo reaches Mercury** — the Europe–Japan probe enters orbit
  after an eight-year journey.

The image was generated by an AI agent from a written brief (bold
newspaper-front-page style: red masthead, navy background, amber accents,
one hero story plus five panels, every headline spelled out in the brief),
then resized to 1024×1024 and quantized to fit the 1 MiB limit. The six
stories were picked from news searches on 23 November 2026 and
cross-checked across several independent sources.

## To run

```sh
python3 main.py
```

This writes the entry image to `/output/entry.png` (890,186 bytes,
1024×1024 PNG). It depends only on the `entry.png` file stored in this
repo — no network access, no randomness — so running it twice produces
byte-identical output.

## To develop

`main.py` is the whole program: it copies `entry.png` verbatim to
`/output/entry.png`. The artwork itself lives in `entry.png`.

The code was written entirely by an AI agent (Muse). A human (the
